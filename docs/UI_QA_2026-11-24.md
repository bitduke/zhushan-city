# 竹山街坊惠全页面测试（2026-11-24）

## 结论

- `src/pages.json` 中的 **27 个页面**均在微信开发者工具中以本机演示模式完成导航、首屏截图和视觉检查：27/27 通过。
- 同一份页面清单切换到正式云环境构建后，27/27 能进入对应路由并渲染页面根节点。无数据、无权限和无效参数时显示空状态或提示；这项检查不等于完成真实业务写入。
- 已验证的界面闭环：演示发布信息 → 待审核 → 管理员审核通过 → 公开列表出现。首页招商跳转、转让/合作筛选、商家入驻跳转和优惠券码页也已抽查。
- 测试发现并修复：券包卡片标题为空；搜索“租房”找不到房屋租售；停用门店直达券管理/预约页时出现未处理权限错误。修复后相关页面已回测，正式云环境当前会给出明确权限提示，控制台未再查到该错误。
- 在上述 27 页测试后新增第 28 页“商圈联盟优惠”：正式云环境已检查页面打开、暂无审核商家的提示，以及首页、券包、逛店和商家申请入口的跳转；该新增页尚未纳入下方原始 27 页机器记录。
- 后续新增第 29、30 页“欢迎使用”“用户服务协议”：首次直达首页会进入欢迎页；未勾选时登录按钮不可用，拒绝后无同意记录；服务协议与隐私说明链接可打开；勾选后建立微信身份并进入目标页，已同意用户重开后直接进入首页。运营管理台直达路径的同意后回跳也已在模拟器验证。微信原生隐私授权按钮已编译输出，但平台隐私指引尚未配置，`needAuthorization=true` 的真机分支待测。
- 按用户反馈清理重复入口后，正式云环境首页复核：六个便民分类、一个商圈联盟卡和一个发布信息卡；原场景小卡、重复商家入驻卡和悬浮发布按钮均不再出现。抽查“房屋租售”进入 `catId=house`、商圈联盟卡进入玩法说明页、发布卡进入发布表单；底部逛店、券包和我的导航仍可用，控制台未查到 `error`。
- 底部“券包”和“逛店”分别核对为 `pages/coupon/mine` 与 `pages/merchant/list`。券包原本的空状态“逛逛好店”按钮会再次跳到逛店，已移除；空券包现只说明到店扫码领券后会保存在此。两页正式云环境截图和直达预览码分别位于 `D:/Ai movies/outputs/zhushan-{wallet,shop}-tab-cloud.jpg`、`preview-zhushan-{wallet,shops}-distinct.jpg`。

## 尚未达到“完整功能通过”的项目

- 微信开发者工具当前无独立测试号；用户确认暂时没有可安排的测试门店或其他微信号。因此居民、店主、员工、管理员四个真实微信身份的跨账号权限链路未完成。
- 真实手机的门店小程序码、摄像头扫码、图片上传/私有资质预览、预约到店和核销仍需真机验收。
- 正式云环境无首批公开商家和便民信息，不能用演示数据替代真实供给验收。
- 名称基础信息仍在审核；注册主体、隐私指引和小程序备案未完成，`pnpm run check:release` 仍阻断版本上传。
