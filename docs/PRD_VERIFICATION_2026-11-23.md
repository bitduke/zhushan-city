## 本轮证据

- `pnpm exec tsc --noEmit`：通过。
- `pnpm run test:cloud`：13 个本地边界测试通过，见 [cloud-core.test.cjs](../tests/cloud-core.test.cjs) 与 [config-consistency.test.cjs](../tests/config-consistency.test.cjs)。
- `pnpm run build:mp-weixin`：Mock 与 `VITE_USE_MOCK=false` 两种配置均可编译；后一配置只使用占位环境 ID 验证构建，**不可运行云端业务**。
- 微信开发者工具 Nightly 的当前小程序测试号模拟器：复核配置停用/恢复、发布表单选项变化、失效门店码提示与返回首页；此前已复核 A/B 券、预约/核销、信息审核与合作演示流程。模拟器数据是本机演示记录，不是线上数据。

## 下一道实际门禁

拿到正式小程序 AppID 与可用云开发环境 ID 后，按 [云端联调清单](CLOUD_READINESS.md) 建集合与索引、部署函数、设置管理员，使用真实的居民、店主、员工和管理员身份逐项验证。完成真机扫码、图片上传、订阅通知及异常场景后才能称为 V1.0 上线验收通过。
